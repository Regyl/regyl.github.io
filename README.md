# Eugene Novikov — Portfolio

Production-quality personal portfolio for Eugene Novikov, Senior Java Software Engineer / Tech Lead.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- Framer Motion
- Lucide icons

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:43123](http://localhost:43123).

## Features

- Interactive terminal with predefined commands
- Security Operations Center dashboard
- Distributed System Playground simulation
- Interview mode with static Q&A dataset
- Research interests notebook
- Recruiter mode toggle
- Command palette (⌘K / Ctrl+K or `/`)
- Easter eggs (Konami code, `sudo hire-eugene`, etc.)
